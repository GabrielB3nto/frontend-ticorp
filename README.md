# Frontend TiCorp

Frontend do projeto TiCorp para gerenciamento de pontos.

## Tecnologias

- React 18+
- TypeScript
- Vite
- Tailwind CSS
- axios para requisições HTTP

## Instalação

```bash
npm install
```

## Desenvolvimento

```bash
npm run dev
```

O projeto rodará em `http://localhost:5173`

## Build

```bash
npm run build
```

## Variáveis de Ambiente

Veja `.env.example` para configurar as variáveis necessárias.
